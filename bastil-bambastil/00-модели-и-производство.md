# Выбор моделей и производственный план

Проект: анимационный ролик для **Белёвской пастильной мануфактуры**. Маскот **Бастил-Бамбастил** даёт отпор серебряным жукам, напавшим на белёвский яблоневый сад с зелёной антоновкой.

Формат финального ролика: **вертикаль 9:16** (Reels / TikTok / VK Клипы), 90 секунд.

## 1. Раскадровка — какая модель

Запрос был «GPT Image Pro». **Модели с таким именем в каталоге Higgsfield нет.** Ближайшее и, по совокупности, правильное — `gpt_image_2`.

| Параметр | Значение |
|---|---|
| ID модели | `gpt_image_2` |
| Название | GPT Image 2 (OpenAI) |
| Тиры качества | `low` / `medium` / `high` — «Pro» соответствует `high` |
| Разрешение | `1k` / `2k` / `4k` |
| Соотношения сторон | 1:1, 4:3, 3:4, 16:9, 21:9, 9:16, 3:2, 2:3 |
| Сильные стороны | рендер текста и типографики, многопанельные раскладки, редактирование |

**Почему она.** Панели комикса несут русские подписи, а GPT Image 2 — единственная модель каталога, у которой рендер текста заявлен как профильная сила. Плюс она держит многопанельную раскладку страницы, что и требуется для комикса.

### Стоимость (проверено preflight-запросом)

| Тир | Кредитов за кадр |
|---|---|
| `high` + `2k` | 8.5 |
| `high` + `4k` | **14** (одинаково для любого соотношения сторон) |

Баланс на момент старта: **1200 кредитов**, план ultimate.

### Резервные модели

| Модель | Когда переключаться |
|---|---|
| `nano_banana_pro` (Google) | если GPT Image 2 не удержит одного и того же Бастила между панелями — Nano Banana Pro сильнее в консистентности персонажа по референсу |
| `seedream_v4_5` (Bytedance) | если понадобится разрешение выше 4K или точное редактирование готовой панели |

## 2. Раскладка страниц комикса

Финал вертикальный, поэтому страница строится так, чтобы **каждая панель повторяла кадрирование будущего ролика**:

- страница — **9:16**
- сетка **2×2**, четыре панели
- каждая панель — 9:16

Математика сходится точно: 2 колонки × 2 ряда панелей 9:16 дают (2×9):(2×16) = 9:16. Панель на странице 4K занимает примерно 1152×2048 — этого хватает, чтобы читать композицию и мимику.

Раскадровка разбита на **12 панелей** (не 8): продюсерская приёмка показала, что в сценах по 4–11 планов и панель не может вместить сцену целиком. Значит **3 страницы на стиль**.

## 3. Объём генерации

| | Количество |
|---|---|
| Стилей комикса | 5 |
| Страниц на стиль | 3 |
| Итого кадров | 15 |
| Стоимость | 15 × 14 = **210 кредитов** |

## 4. Обязательная процедура консистентности

Без неё на выходе будет не один Бастил, а двенадцать разных. Порядок:

1. Сначала генерится **turnaround-лист** Бастила и главаря жуков — 3 ракурса, нейтральный фон. Утверждается заказчиком.
2. Все панели идут **только как reference / img2img от утверждённого turnaround**.
3. В каждом промпте **первым абзацем — дословный CHARACTER LOCK**, скопированный без изменений; сцена только вторым абзацем.
4. В каждом промпте — единый **negative-блок**.

Отдельно: слово `beetle` из промптов убрано полностью. На него любой генератор даёт шесть ног, хитин, фасеточные глаза и органический глянец — ровно то, что запрещено дизайном. Вместо него `chrome capsule character`, `tin wind-up toy figure`, `mirror-polished figure`.

## 5. Видеогенератор — решение отложено

Выбирается после утверждения стиля комикса. Кандидаты из каталога:

| Модель | Длительность | Чем интересна |
|---|---|---|
| `cinematic_studio_3_0` | 4–15 с | до 4K, жанровые подсказки, генерация звука |
| `seedance_2_5` | 4–30 с | омни-референсы, видеомонтаж и продление клипа |
| `seedance_2_0` | 4–15 с | референсы с удержанием идентичности, до 4K |
| `minimax_h3` | 4–15 с | 2K, ключевые кадры start/end |
| `flux_3_video` | 5–20 с | старт- и энд-кадр, синхронный звук |
| `kling3_0` | — | мультисцен, звук, перенос движения |

Ключевое требование к выбору: поддержка **start_image + end_image**, иначе персонаж поплывёт между кадрами. Ему отвечают `seedance_2_0`, `seedance_2_5`, `minimax_h3`, `flux_3_video` и `cinematic_studio_3_0`.

## 6. Вопросы, которые сценарием не решаются

Вынесены из продюсерской приёмки, требуют решения заказчика:

1. **Права на наименование «Белёвская».** Географически связанное наименование. Если мануфактура не правообладатель НМПТ — титр придётся менять, а вместе с ним обесценится весь мир ролика (Белёв, Ока, сушильня, кружево). Проверять **до** аниматика.
2. **Формулировка состава в титре.** Это утверждение о составе в рекламе — должно соответствовать реальной рецептуре и быть подписано технологом. Отдельно вопрос по аллергенам, если продукт рекламируется детским хором.
3. **Проверка по ст. 6 ФЗ «О рекламе»** связки «детский хор + маскот + кондитерское изделие».
